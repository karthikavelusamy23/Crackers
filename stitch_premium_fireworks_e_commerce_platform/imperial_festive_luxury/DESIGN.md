## Brand & Style

This design system embodies high-end celebratory Indian luxury: vibrant, sun-drenched, radiant, and architectural. It captures the majesty of Indian festivals—Diwali galas, royal weddings, and grand heritage celebrations—through luminous daylight palettes rather than nocturnal backdrops. 

The aesthetic marries modern Indian minimalism with regal craftsmanship. High-contrast, razor-sharp architectural geometry establishes an uncompromised sense of precision and luxury. Every boundary is crisp, deliberate, and definitive.

Visual style attributes:
- **Luminous Radiance:** Light-drenched surfaces layered in warm ivory, sunlit creams, and soft celebratory pastels evoke silk brocades and marigold-strewn courtyards.
- **Architectural Crispness:** Structured, monolithic frames and gallery-style product showcases.
- **Opulent Modernity:** Vivid radiant crimson, vibrant saffron container, and imperial antique gold accents punctuate pristine pastel planes, complemented by clean modern geometric typography.

## Color Tokens & Vibrant Palette

The palette is strictly radiant, celebratory, and warm. Depth is produced through tonal pastel layering and warm metallic boundaries.

### Primary & Action Colors
- **Radiant Festive Crimson (`#D92500`):** Core brand action color; primary CTAs, active states, and discount badges.
- **Crimson Hover (`#B31A00`):** Interactive hover state for primary action buttons.
- **Primary Container (`#FF3B14`):** High-energy highlight bursts and urgent alert ribbons.
- **Vibrant Saffron Container (`#FF961F`):** Secondary accent, category badges, and active focus boundaries.
- **Rich Sienna (`#A05200`):** Secondary navigation links, brand sub-headers, and accent icons.
- **Imperial Antique Gold (`#E5A910`):** Crests, ratings, heirloom seals, and luxury hairlines.
- **Deep Festive Umber (`#241815`):** Primary text color providing crisp contrast on daylight surfaces.
- **Muted Walnut (`#5B403B`):** Secondary specifications, batch information, and technical parameters.

### Surfaces & Pastels
- **Warm Ivory Baseline (`#FFFDF9` / `#FFFDF8`):** Canvas baseline across all catalog and content pages.
- **Pale Champagne Cream (`#FFF8EB`):** Container sections, header bars, and drawer panels.
- **Delicate Blush Saffron (`#FFF1EC` / `#FFF2EC`):** Promotional callouts and modal backdrop washes.
- **Pastel Festive Peach (`#FEECE5` / `#FFEAE0`):** Card containers and specification striping.

## Animation & Motion Design Tokens

All interactive transitions follow a custom high-energy easing curve: `cubic-bezier(0.16, 1, 0.3, 1)`.

### Keyframe Definitions
```css
/* Staggered entrance animation for product catalog cards */
@keyframes cardEntrance {
  0% {
    opacity: 0;
    transform: translateY(16px) scale(0.985);
  }
  100% {
    opacity: 1;
    transform: translateY(0) scale(1);
  }
}

/* Luminous badge and active indicator pulse */
@keyframes pulseGlow {
  0%, 100% {
    opacity: 1;
    transform: scale(1);
  }
  50% {
    opacity: 0.85;
    transform: scale(1.03);
  }
}

/* Top announcement shimmer */
@keyframes shimmerBanner {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}
```

### Component Transitions & Micro-Interactions
- **Product Card Hover:** `transform: translateY(-5px); box-shadow: 0 16px 32px -8px rgba(217, 37, 0, 0.18), 0 4px 12px rgba(229, 169, 16, 0.14); border-color: #FF961F;`
- **Product Card Image Zoom:** `transform: scale(1.06); transition: transform 0.42s cubic-bezier(0.16, 1, 0.3, 1);`
- **Category Filter Buttons:** `transform: translateY(-1.5px)` on hover, `transform: scale(0.97)` on active click.
- **Add to Burst Box Buttons:** `transform: translateY(-1.5px)` with elevation glow on hover, `transform: scale(0.96)` on tap.

### Motion Safety Compliance (`prefers-reduced-motion`)

    animation-duration: 0.001ms !important;
