# Sovereign Pyrotechnics

This is a static, multi-page implementation of the supplied designs. Every route is a verbatim page export so its source markup, Tailwind configuration, typography, colors, imagery, and in-page interactions are preserved exactly.

## Routes

- `/` — Home
- `/home_bright_pastel_festive_edition/` — Home
- `/products_bright_pastel_festive_catalog/` — Products catalog
- `/product_detail_120_shot_brocade_bright_pastel_edition/` — Product detail
- `/billing_checkout_bright_pastel_edition/` — Checkout
- `/payment_confirmation_order_status_sovereign_pyrotechnics/` — Payment confirmation
- `/about_us_heritage_purity_editorial_modern_edition/` — About
- `/contact_store_locator_bright_pastel_edition/` — Contact and store locator

## Styling system

The pages embed their supplied Tailwind theme and use Outfit for display and labels and Plus Jakarta Sans for body copy. The shared visual language is warm ivory and pastel surfaces, deep umber text, vermilion primary actions, marigold accents, and antique-gold borders. The canonical tokens and typography specification remain in `stitch_premium_fireworks_e_commerce_platform/imperial_festive_luxury/DESIGN.md`.

## Preview

Open `index.html` in a browser, or serve this folder with any static web server.
